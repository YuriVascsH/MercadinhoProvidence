# Sistema PDV para o Mercadinho Providence

Este projeto consiste em um sistema de **Ponto de Venda(PDV)** desenvolvido em **Java** com interface gráfica construída em **JavaFX** e persitência de dados utilizando **MySQL**.

O objetivo é criar uma solução simples e eficiente para **Automatizar as vendas, controle de estoque e registro de produtos e/ou funcionários** de um mercadinho local.

---
## Funcionalidades
- Registro de vendas com cálculo automático de troco
- Cadastro e consulta de produtos
- Controle de estoque com atualização
- Cadastro de funcionários
- Relatório simples de vendas

---

## Teconlogias Utilizadas

- [Java]
- [JavaFX]
- [MySQL]

---
## ✅ Requisitos para rodar o projeto

Antes de iniciar, certifique-se de ter os seguintes softwares instalados:

- Java JDK 17 ou superior
- MySQL Server
- IDE com suporte a Java (como IntelliJ IDEA, Eclipse ou NetBeans)
- JavaFX SDK
- Driver JDBC do MySQL
